# 이전 다중 그룹 테스트 원본

이 파일들은 다중 그룹 스키마 시절의 사양이며 `.ts.legacy` 확장자로 보관한다. 기존 `resetDb()`는 공유 로컬 DB의 사용자와 기록을 지우므로 실행하지 않는다.

현재 사양의 DB·권한 검증은 `tests/integration/single-club.test.ts`에서 수행한다. 실제 Postgres를 사용하며 모든 시험은 롤백한다. 가입·중복 신청·승인·거절·탈퇴·관리자 이양·초대 만료/취소·모임/발제/참석/한줄 평 권한·파일 경로 권한·보관 데이터 격리를 검증하고, 실행 전후 기존 레코드의 지문을 비교한다.
