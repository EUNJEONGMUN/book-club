## 실행 전 남은 준비

1. **관리형 테스트 실행 경로 검증 완료:** 고정 테스트 프로젝트의 별도 합성 DB에서 전환/복구, 기존 Preview에서 실제 Auth/REST/표준·서명·TUS 파일 쓰기 차단/해제, 차단 중 백업의 격리 복원을 시험해 **337개 검사**를 통과했다. 기존 테스트 기록·파일을 보존했고 Python 안전 검사44개 통과. [상세 결과](hosted-cutover-verification.md). 기존 로컬 SQL 생성기의 운영 DB명 거절 제한은 유지하며 새 어댑터도 테스트 연결만 허용한다. 운영 접속 경로와 당일 대상·최종 백업/복원 증거를 연결하는 작업은 별도다. S3/Google의 관리형 재시험과 이미 전송 중인 HTTP 본문 종료는 이 결과에 포함하지 않는다.
2. **배포·복구 후보 소스 준비 완료:** 점검 브리지/새 앱/구 구조 복구 앱 3개를 고정 소스 패키지로 만들고 Node24·기본 Next 빌드 3개 및 응답 검사23개, 안전 검사48개를 통과했다. 실제 배포는 0개이며 [후보 준비 결과](release-candidate-preparation.md)를 따른다. main 자동 운영 배포/도메인 연결은 켜진 채 유지했다. Hobby의 직전 배포 롤백 제한 때문에 미승격 복구 후보를 별도로 준비하는 계획이다. 승인 후 Production 환경에서 도메인 미연결 후보를 생성·보호 확인해야 하며 Preview 결과물을 그대로 운영에 연결하지 않는다.
3. **운영 실행 경로·최종 백업 연결 구현·격리 검증 완료:** 별도 운영 전송 계층/단계 엔진/최종 묶음 수집/전체·public·파일 실제 복원을 연결했다. 서버의 같은 실행/릴리스에 실제 복원 해시가 등록돼야 SQL을 허용하며 온라인 사본·다른 실행·손상 사본은 거절한다. [67+390개 검증 결과](operational-backup-linkage.md). 아직 운영에서 실행한 상태가 아니다.
4. **인증 갱신/기존 로그인 보존 보완 — 현재 선행 조건:** 전체 Auth 차단의 HTTP500에 SDK가 세션을 지우는 경로를 해결·실제 서비스/SDK로 검증한다. 현재 실제 운영 실행은 하드 차단 상태다. 이 조건을 해결하기 전에는 점검·쓰기 차단을 시작하지 않는다.
5. **점검 시간·담당자·승인 확정:** 위 보완 후 사용자 안내 시간, 진행 담당자, 복구 판단 담당자를 정하고 예상 중단과 복구 방식을 설명한 뒤 운영 실행을 승인받는다. 비밀번호·키를 재발급하는 절차가 아니다.

## 중단과 복구의 경계

- **DB 전환 전 중단:** 점검/차단을 유지하며 실패 원인을 확인한다. DB가 원래 구조·원본 그대로인지 확인한 뒤 구 앱을 유지하고 차단을 해제할 수 있다. 실패한 차단 설치 트랜잭션은 전체 롤백 여부부터 확인한다.
- **전환 후, 쓰기 재개 전 실패:** 현재 실패 상태도 별도 백업하고 보존한다. 시험한 방식대로 전환 앱 객체·새 이력을 비공개로 옮기고, **당일 최종 public 백업**으로 구 앱 구조·업무 데이터·RLS/Storage 정책·원래 적용 이력을 복구한다. public 스키마 OID·관리형 기본 권한과 Auth/Storage 레코드·파일은 유지한다. 구 앱 호환성과 모든 원본을 다시 대조하기 전 차단을 풀지 않는다. 일부 SQL만 적용된 경우도 실제 이력에 맞춰 판단하며 파일 이름만 보고 성공으로 처리하지 않는다.
- **쓰기 재개 후 실패:** 다시 차단하고 현재 DB/파일부터 새로 보존한다. 재개 이후 가입·수정·업로드를 대조·병합하는 계획을 검증한다. 예전 사본으로 즉시 덮어쓰지 않는다.
- **예상 밖 Auth/Storage 자체 손상:** public 복구만으로 해결됐다고 판단하지 않는다. 전체 백업·파일을 함께 보존하고 별도의 복구 범위를 먼저 검증한다. 관리형 스키마 전체 교체를 즉흥적으로 시도하지 않는다.

공통 중단 기준은 대상 불일치, 승인 없는 변경, 백업/복원/파일 대조 실패, 진행 중 쓰기 미확인, 보호 누락, 새 기록 손실 가능성이다. 중단은 삭제·초기화·비밀번호 재설정·이전 백업 덮어쓰기를 의미하지 않는다. 기존 보관본·실패 사본·백업은 자동 삭제하지 않는다.
