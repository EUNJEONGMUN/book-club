# 부글부글 기능과 권한

부글부글은 Next.js App Router와 Supabase를 사용한다. 운영 앱은 Vercel 서울 리전에 배포한다. 로컬 실행과 환경변수는 [부트스트랩](bootstrap.md)에 있다.

## 모임과 링크 공유

- 홈(`/`)에는 다음 모임과 참석 현황을 표시한다. 모임(`/meetings`)은 다가오는 일정과 지난 일정을 나눠 보여준다. 지난 모임은 연도별로 조회하고, **모아보기**에서 해당 연도의 책을 월별 책장으로 볼 수 있다. 홈과 책장에서 연 상세 화면은 각각 홈과 같은 연도의 책장으로 돌아간다. 일정과 멤버 이력의 월은 한국 시간(`Asia/Seoul`)으로 표시한다. 홈과 상세의 D-Day는 한국 달력 날짜 차이로 계산한다. 상세에서 모임 날짜가 지나면 배지를 숨긴다.
- 승인된 회원은 모임 상세, 발제 질문, 참석 현황을 조회한다. 발제자는 등록 시 작성자가 기본값이며, 수정 권한이 있는 회원은 다른 승인 멤버를 발제자로 지정할 수 있다. 작성자는 본인 모임을 수정·삭제할 수 있다. 관리자는 시작 시각이 지난 모임의 발제자, 책, 일시, 장소, 발제 질문과 첨부 자료를 수정할 수 있다. 회원은 다가오는 모임에서 본인의 참석 여부를 변경할 수 있으며, 작성자와 관리자는 지난 모임 상세에서 참석 기록을 정정할 수 있다.
- 상세 화면의 **모임 링크 공유**를 누르면 클립보드 복사와 기기 공유 메뉴 열기를 함께 시도한다. 복사가 성공하면 완료 메시지를 표시하고, 두 동작이 모두 실패하면 복사용 입력창을 표시한다. 홈에서 열었을 때 붙는 `from=home`은 공유 주소에서 제거한다.
- 모임 등록·수정 폼은 입력 이름과 검증 오류를 해당 입력에 연결한다. 이동 링크는 키보드로 실행할 수 있고, 발제 질문의 수정·삭제 버튼에는 질문 번호와 동작을 나타내는 접근성 이름이 있다. [PR #86](https://github.com/EUNJEONGMUN/book-club/pull/86)

## 테마

- **설정 → 테마 변경**에서 기본과 크리스마스 테마를 선택할 수 있다. 선택한 테마는 즉시 적용된다.
- 선택 가능한 테마와 기본값은 `lib/theme.ts`에서 등록한다. 사용자의 선택은 기존 브라우저 저장 키 `book-club-theme`에 보관한다.
- `app/globals.css`의 공통 색상은 화면, 카드, 입력, 버튼, 포커스와 상태의 역할별로 정의한다. 시즌 팔레트와 패턴, 장식은 `app/themes/christmas.css`처럼 시즌별 CSS에 둔다.
- 시즌을 추가할 때 테마 목록에 이름을 추가하고, `app/globals.css`에서 시즌 CSS를 가져온다. 아이콘과 장식은 필요한 역할만 각각 `SeasonalIcon`과 `SeasonalDecoration`에 등록하고, 시즌 CSS에서 해당 요소를 표시한다. 대체 아이콘이 없는 역할은 기본 아이콘을 표시한다.
- `data-slot`은 컴포넌트, `data-part`는 내부 영역, `data-field`는 입력의 역할을 표시한다. 입력의 고유 ID는 화면과 역할을 앞에 붙여 레이블과 검증 메시지 연결에 사용한다.

## 가입과 프로필

관리자의 초대 링크에서 로그인 또는 가입 후 프로필을 등록하고 가입을 신청한다. 신청 직후 `/pending`에서 승인 상태를 확인한다. 이메일·비밀번호와 Google 로그인을 지원한다. 미가입 상태의 안내 화면은 `/onboarding`이다.

프로필 생성은 서버가 확인한 계정 ID와 DB의 본인 생성 정책을 사용한다. 중복 생성 요청은 처음 저장한 이름을 보존한다. 설정(`/more`)에서 내 프로필과 그룹 설정을 열 수 있고, 관리자는 가입 신청 관리(`/more/applicants`)를 이용할 수 있다.

**설정 → 프로필 → 로그인 수단**에서 기존 계정에 Google 로그인을 연결할 수 있다. 연동 후에도 기존 계정의 프로필과 멤버십으로 접속한다. 승인된 회원은 멤버 화면(`/members`)에서 다른 승인 멤버의 참석·발제 이력을 볼 수 있다.

그룹 설정(`/more/info`)에서 관리자는 초대 링크를 발급·재발급하고 전체 주소를 복사할 수 있다. 만료 시각은 DB에 기록된 값을 한국 시간으로 표시한다. [PR #84](https://github.com/EUNJEONGMUN/book-club/pull/84)

## 한줄 평

모임이 시작되면 작성자 본인이 한줄 평을 작성하거나 수정할 수 있다. 원본 테이블은 본인의 행만 읽을 수 있으며, 앱은 DB 함수 `get_meeting_reviews`로 조회한다. 이 함수는 다른 회원에게 비공개 평을 반환하지 않는다. 익명 평은 작성자 ID와 아바타를 숨기고 이름을 `익명`으로 표시한다.

## 발제 파일

- 모임 수정 권한이 있는 작성자 또는 관리자는 PDF 또는 이미지(최대 20MB)를 브라우저에서 Supabase Storage로 직접 올린다. 6MB를 넘는 파일은 TUS를 사용해 연결이 끊기면 전송을 이어간다. 한글 파일명은 DB에 따로 저장하고 다운로드 시 사용한다.
- 모임 상세의 파일 링크는 참석 여부와 관계없이 승인된 회원에게 보인다. 공개 파일 URL을 받은 사람은 로그인 없이 다운로드할 수 있다.
- 교체와 모임 삭제는 DB 반영을 확인한 뒤 기존 파일을 정리한다. DB 반영이 실패하거나 확인되지 않으면 기존 파일을 보존한다. 모임 삭제 후 늦게 끝난 업로드는 유효한 완료 요청을 받아 정리하며, 요청이 오지 않으면 새 파일이 남을 수 있다.
- 모임 수정 권한이 있는 작성자 또는 관리자는 현재 첨부한 PDF에서 Gemini로 질문 초안을 추출해 검수한 뒤 저장할 수 있다. 서버는 DB에 등록된 파일의 경로를 정규화하고 해당 모임의 Storage 경로인지 검증한다. 파일을 가져올 때 리다이렉트를 차단한다. [PR #83](https://github.com/EUNJEONGMUN/book-club/pull/83)
- 추출에 실패하면 다시 시도할 수 있다. 저장에 실패하면 검수 중인 질문을 보존하고 저장 버튼을 다시 활성화한다. 응답이 끊겨 저장 결과가 불확실한 경우에는 목록을 확인한 뒤 재시도하도록 안내한다. [PR #85](https://github.com/EUNJEONGMUN/book-club/pull/85)

## 발제 질문 저장

단건과 일괄 등록은 DB 함수 `append_discussion_questions`로 순번을 배정한다. 동시에 요청해도 같은 모임의 순번은 겹치지 않고 일괄 입력의 순서는 유지된다. 수정·삭제는 실제 반영된 행이 있을 때 성공을 반환한다. 순번 제약과 DB 함수는 기존 운영 Supabase의 마이그레이션 `20261112000001`에 포함돼 있다. [PR #84](https://github.com/EUNJEONGMUN/book-club/pull/84)

## 데이터 구조

회원 자격과 관리자 권한은 `members.role`로 결정한다. `club_settings`는 한 행을 사용하고 초대 링크는 `invites`에서 관리한다. 일정과 발제 질문, 참석, 한줄 평은 기존 ID로 연결한다. 이전 그룹 자료와 변경 전 프로필·일정은 외부 API에 노출하지 않는 읽기 전용 `legacy_multiclub`에 보관한다. 예전 부글부글 주소는 `legacy_club_id`로 새 주소에 연결한다.

모임의 작성자는 `meetings.created_by`, 발제자는 `meetings.host_id`에 저장한다. 마이그레이션 `20261119000001`은 기존 모임의 작성자를 당시 발제자로 채우고 작성자·관리자 권한을 갱신한다. 이어서 `20261119000002`는 모임 수정 권한이 있는 회원에게 발제자 변경을 허용하고 새 발제자가 승인된 멤버인지 검증한다.

| Storage 버킷 | 용도 | 최대 크기 | 다운로드 |
| --- | --- | --- | --- |
| `avatars` | 프로필 사진 | 5MB | 공개 URL |
| `book-covers` | 책 표지 | 5MB | 공개 URL |
| `discussion-files` | 발제 PDF·이미지 | 20MB | 공개 URL |
