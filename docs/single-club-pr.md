# PR 본문

부글부글 하나만 사용하는 서비스에 맞춰 그룹 생성·선택·삭제 흐름을 제거하고 `/meetings`, `/members`, `/more` 중심으로 화면과 서버 처리를 전환한다. 기존 부글부글 주소는 새 경로로 연결하고 다른 모임 ID는 거절한다.

DB는 `club_settings`, `members`, `invites`를 사용한다. 기존 계정·역할·가입 시각·모임 ID·발제·출석·후기·초대·파일 경로를 보존하고, 원래 그룹 테이블과 변환 전 프로필·모임은 비공개 읽기 전용 `legacy_multiclub`에 보관한다. 지난 모임 출석 수정과 발제 자료 쓰기 권한도 정리했다. 백업·격리 복원·단계별 SQL·검증·복구 도구를 함께 포함한다.

## 운영 상태

2026-11-11 소유자의 승인과 직접 실행으로 운영 DB 전환(02→03→04), 새 앱 승격, 임시 쓰기 차단 해제를 완료했다. 현재 운영 앱과 이 PR의 앱 소스가 같으며, 이 병합은 main을 실제 운영 소스와 동기화한다. 앱 배포 과정에서 DB 전환 SQL을 재실행하지 않는다.

최종 백업·파일은 로컬 비공개 보관하고 Git에 포함하지 않았다. 재개 이후에는 새 기록이 생기므로 이전 백업을 운영 DB에 덮어쓰지 않는다. 상세 기록은 `docs/manual-production-cutover.md`에 있다.
